    basicsSign

    • basicsSign(
          allowedStorages: string[] | null,
          format: string,
          data: string | string[],
          signingParams: Object,
          signerParams: Object,
          locale: string,
          forceSingleSignature?: boolean,
      ): Promise<string | string[]>

      Вычислить подпись под данными с указанными параметрами. Новая функция sign 2022 года из модуля kz.gov.pki.knca.basics (https://github.com/pkigovkz/sdkinfo/wiki/KNCA-Basics-Module). Сигнатура функции сложная, поэтому рекомендуем пользоваться функциями помощниками basicsSignXLM и basicsSignCMS.

      Parameters

      • allowedStorages: string[] | null

        массив строк с константами допустимых для использования типов хранилищ (см. константы basicsStorage*).

      • format: string

        тип вычисляемой подписи: 'xml', либо 'cms'.

      • data: string | string[]

        подписываемые данные.

      • signingParams: Object

        параметры подписания (см. basicsCMSParams* и basicsXMLParams*).

      • signerParams: Object

        параметры выбора сертификата для подписания (см. константы basicsSigner*).

      • locale: string

        язык пользовательского интерфейса.

      • forceSingleSignature: boolean = false

        возвращать только одну подпись даже если получили массив, используется для обеспечения обратной совместимости работы с CMS.

      Returns Promise<string | string[]>

      подпись или массив подписей.

      Throws

      NCALayerError

      Вычислить CMS подпись под данными с указанными параметрами, это функция-помощник для упрощения работы с функцией basicsSign.

      В том случае, если библиотека смогла обнаружить HTTP API KAZTOKEN desktop на локальном компьютере, она будет пробовать использовать его для подписания в том случае, если это не было запрещено при вызове конструктора (параметр allowKmdHttpApi).

      Parameters

      • allowedStorages: string[] | null

        массив строк с константами допустимых для использования типов хранилищ (см. константы basicsStorage*).

      • data: string | ArrayBuffer | Blob | File | (string | ArrayBuffer | Blob | File)[]

        данные, которые нужно подписать, в виде строки Base64, либо ArrayBuffer, Blob или File. Так же поддерживается массив документов.

      • signingParams: BasicsCMSSigningParams

        параметры подписания (см basicsCMSParams*).

      • signerParams: Object

        параметры выбора сертификата для подписания (см. константы basicsSigner*).

      • Optionallocale: string = 'ru'

        язык пользовательского интерфейса.

      Returns Promise<string | string[]>

      подпись, либо массив подписей если на подписание был передан массиов документов.
